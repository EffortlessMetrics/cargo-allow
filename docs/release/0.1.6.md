# 0.1.6 Release Record

This records the completed `0.1.6` patch release after the published `0.1.5`
crate set.

The release is irreversible now that packages are published. If a published
package is wrong, the rollback path is to yank the affected version and publish
a fixed patch release. Do not reuse `0.1.6` for corrected contents.

## Target Claim

The 0.1.6 release keeps the 0.1.x claim:

```text
cargo-allow inventories syntax-visible source exceptions and checks them
against a policy ledger.
```

It may additionally say that Rust source-syntax identity is more precise for
unsafe, panic-family, indexing, slicing, lint-attribute, trait-method, and
extern-signature findings, and that legacy migration preserves more evidence
from Clippy, no-panic, non-Rust, file-policy, workflow, dependency, and
process/network policy lanes.

It must not claim macro-expanded, type-aware, MIR-level, build-aware,
control-flow, data-flow, unsafe-proof, test-adequacy, or coverage-proof
analysis.

## Release Scope

0.1.6 is a patch release for product hardening merged after 0.1.5:

- Migration preserves recognized and unstructured evidence across Clippy,
  no-panic, non-Rust, generated/executable file-policy, workflow/dependency,
  and process/network legacy policy lanes.
- Migration honors root-relative evidence references when converting legacy
  `from` sources.
- Rust source-syntax scanning records stronger structural identity for unsafe
  impls, unsafe extern blocks, unsafe item containers, unsafe attribute targets,
  trait-method containers, extern signatures, lint-attribute target scope,
  panic-family macro paths, nested panic receivers, index expressions, and
  string slicing.
- The panic fixture policy now matches the current source-syntax scanner shape
  without weakening the source-tree/no-new claim.
- Repo-local AGENTS guidance now matches the actual PR, swarm, and release
  operating model.

Non-goals for 0.1.6:

- No scanner, matcher, migration, or policy broadening to make checks pass.
- No claim of build-aware, Cargo-metadata, Clippy, rustc, proc-macro, or
  proof-tool execution.
- No laundering generated `baseline_debt` into reviewed approval.

## Known Limitations

contents.
