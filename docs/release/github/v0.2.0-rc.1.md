# cargo-allow v0.2.0-rc.1

> **Draft candidate — not published.** This file does not authorize namespace
> publication or a `v0.2.0-rc.1` tag.

Candidate for the first cargo-allow release on Rust 1.95, with the fast
structured finding-to-receipt workflow and topology-derived release evidence.

## Highlights

- **MSRV raised to Rust 1.95** — the 0.1.x line remains on 1.85
- **`add --update`** — atomic in-place ledger mutation, no more `--force` dance
- **`why` single-file fast path** — 73x faster than full audit for one-finding questions
- **`why --plan` + `add --from-plan`** — structured finding-to-receipt handoff with targeted recheck
- **Actionable read surfaces** — `check` remediation roadmap, `diff` why/add suggestions, `list` next-steps, `doctor` repair hints
- **Release evidence contract** — topology-derived `ReleaseManifestV2`; actual
  token-backed publication and attestation remain conditional on the authorized
  workflows succeeding
- **Command migration parity** — the older command-level corpus is complete;
  three-product extraction remains `contract_only`, `Blocked`, and
  `OldPathStillReachable`
- **Performance budgets** measured and documented

## Install

Use this command only after crates.io publishes the exact `0.2.0` package and
the tag workflow's install smoke succeeds:

```bash
cargo install cargo-allow --version 0.2.0 --locked
```

## Claim Boundary

cargo-allow is a source-syntax policy linter and durable exception ledger —
not a compiler, Clippy replacement, or semantic proof system. It scans
source-tree inventory without executing repository code.
