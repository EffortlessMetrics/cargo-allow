# cargo-allow v0.1.10

cargo-allow v0.1.10 is a maintenance and adoption-trust patch for the
source-tree exception ledger. It keeps the 0.1.x claim boundary and does not
raise the Rust MSRV.

Default cargo-allow behavior remains the source-exception ledger:

```bash
cargo-allow audit
cargo-allow check --mode no-new
cargo-allow diff --base origin/main
cargo-allow worklist --format json
```

## Highlights

- Carries the portable governance substrate and `.allow/` profile migration
  groundwork for repo-owned source truth.
- Adds multi-ledger federation, mirror-divergence visibility, and
  ledger-coherence change-control foundations.
- Improves diff movement/posture classification and required-change-note
  enforcement for weakening edits.
- Hardens first-hour adoption docs, GitHub Actions examples, and release
  automation.
- Fixes accumulated scanner, matcher, inventory, CLI, evidence-path, schema,
  report, and refresh regressions found after 0.1.9.

## Install

```bash
cargo install cargo-allow --version 0.1.10 --locked
```

## Claim Boundary

cargo-allow scans source-tree inventory without executing repository code. This
release improves ledger reliability and adoption ergonomics; it does not add
macro-expanded, type-aware, MIR-level, build-aware, control-flow, data-flow,
unsafe-proof, test-adequacy, or coverage-proof behavior.
