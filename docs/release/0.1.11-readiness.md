# 0.1.11 ReleaseQualificationV1

Assessed against current `main` at the HEAD that includes #2342 (MSRV CI),
#2344 (inventory recursion bounds), #2345 (glob step budget), and #2346 (cargo
allow shim scoping), refreshed 2026-07-16. The candidate version remains
provisional; the workspace is currently `0.1.10`.

This is a **0.1.x** qualification on **Rust 1.85**. A later MSRV raise to 1.95
belongs with the `0.2.0` train, not this patch release.

## Decision

```text
candidate_ready = false
tag_ready = false
publication_performed = false
```

The supported exception-ledger core and first-hour read surfaces continue to
harden. Source safety bounds (oversized reads, recursive inventory, glob
backtracking) and MSRV CI are closed on main. Remaining candidate blockers are
package/install smoke and compatibility freeze; tag blockers remain Trusted
Publishing and signed multi-crate provenance.

## Gate reasons

`candidate_ready` becomes true only after:

1. #2256 proves the exact source candidate package/install path on every
   claimed platform. The hosted Linux `package-smoke` receipt now satisfies the
   narrow-claim minimum; a multi-platform claim still needs Windows/macOS
   candidate receipts,
2. #2261 freezes the 0.1.11 capability matrix, version, and changelog.

`tag_ready` additionally requires Trusted Publishing and the signed multi-crate
manifest from #2115/#2047.

This report authorizes no version bump, tag, registry publication, or signed
release-manifest completion. It keeps the next cut as **0.1.11 on Rust 1.85**,
not 0.2.0.
