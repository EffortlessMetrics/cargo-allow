# cargo-allow release notes

Release records are maintained in [`docs/release/`](../../release/README.md)
and the curated [`CHANGELOG.md`](../../../CHANGELOG.md). The current supported
published line is `0.1.11`; `0.2.0` remains a source-candidate release
contract until its independent gates and authorization are complete.

Release notes describe the exact version, changed claim surface, proof
commands, limitations, and follow-up work. A merged change, green CI run, or
local package is not by itself publication or release authorization.

The cargo-allow release rail is independent from optional experimental product
channels. References to those channels must retain explicit opt-in and
experimental framing; installing cargo-allow does not install or support them.

See the [release operations runbook](../../release/README.md) before preparing
a release. This page does not authorize tagging, publishing, or credentials.
